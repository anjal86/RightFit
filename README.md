# RightFit Allied Health Services — Website concept v1

A responsive, four-page static website concept created from the RightFit logo/service artwork supplied by the client.

## Pages

- `index.html` — homepage, value proposition, service highlights, how to get started
- `about.html` — people-centred approach and guiding values
- `services.html` — four service areas drawn from the supplied artwork
- `contact.html` — contact information placeholders and an **enquiry draft** interface

## Brand

- Deep teal `#193D44`
- Forest green `#365849`
- Sage `#799487`
- Copper `#BD815D`
- Warm cream `#F7F3EC`

The logo, illustrations, service names and tagline were sourced from the supplied RightFit logo artwork. Text descriptions of each service are draft marketing copy and need client review.

## To preview

Open `index.html` directly in a modern browser, or serve this folder with any static web server, for example:

```bash
python3 -m http.server 8000
```

Visit `http://localhost:8000` if running on your own machine. No build tooling or backend is required for the page layout.

## Important: not ready for public launch

1. Add the verified RightFit phone number, public email address, location(s), service areas, hours, and referral process.
2. Confirm service descriptions, actual offerings, practitioner qualifications, eligibility, age ranges and waitlist/availability.
3. Check NDIS registration status **before** stating registration or making any NDIS-specific claims.
4. Connect an approved secure form endpoint, with spam protection and appropriate privacy handling; the current button **only copies/downloads an enquiry draft** and does not send or store visitor data.
5. Have the business approve its privacy policy, accessibility content and any required legal information before publishing.
6. The site deliberately includes `robots: noindex,nofollow` while it is a concept. Remove this only when the content is approved and the site is ready to be indexed.
7. Confirm domain and hosting before publishing.
